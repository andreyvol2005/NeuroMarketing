# NeuroMarketing — лендинг онлайн-курса

[![Deploy static site](https://github.com/andreyvol2005/NeuroMarketing/actions/workflows/deploy.yml/badge.svg)](https://github.com/andreyvol2005/NeuroMarketing/actions/workflows/deploy.yml)

Одностраничный лендинг курса «Нейросети для маркетологов: от идеи до результата за 4 недели».

Проект создан в рамках лабораторной работы №4 (генерация с помощью LLM), развивался
в лабораторной работе №5 (публикация в GitHub, работа с ветками, доработка с помощью
AI-агента и публикация через GitHub Pages) и в лабораторной работе №6 (автоматизация
развёртывания через GitHub Actions).

**Опубликованный сайт:** https://andreyvol2005.github.io/NeuroMarketing/

## Как устроена публикация

При каждом push в ветку `main` запускается workflow `.github/workflows/deploy.yml`:

1. `lint` — проверяет HTML и CSS скриптом `scripts/check_site.py`;
2. `deploy` — собирает артефакт и публикует сайт на GitHub Pages.

Если проверка не проходит, деплой не запускается — на сайте остаётся предыдущая версия.

## Структура проекта

- `index.html` — разметка страницы;
- `css/style.css` — стили;
- `img/` — изображения для страницы;
- `scripts/check_site.py` — линтер разметки и стилей;
- `.github/workflows/deploy.yml` — CI/CD-пайплайн.

## Разделы страницы

1. Шапка (sticky) — логотип и кнопка «Контакты»;
2. Hero-блок — слоган, кнопка «Оставить заявку», статистика курса;
3. Преимущества — три карточки;
4. «Как устроено обучение» — описание программы;
5. CTA-блок на контрастном фоне;
6. Контакты — форма обратной связи и реквизиты;
7. Подвал.

## Как запустить

Открыть файл `index.html` в браузере или воспользоваться расширением Live Server в VS Code.
Перед публикацией проверить проект локально:

```bash
python scripts/check_site.py
```
